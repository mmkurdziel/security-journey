## Cele egzaminu (checklista)

Pobierz oficjalny PDF z celami SY0-801 ze strony CompTIA i rozwiń każdą domenę do pojedynczych punktów. Poniżej skrót z oficjalnej strony.

### D1 General Security Concepts (16%)
- [ ] Typy kontroli i jak się uzupełniają
- [ ] Wpływ change management na bezpieczeństwo
- [ ] Kryptografia: szyfrowanie, certyfikaty, hashe, podpisy, zarządzanie kluczami

### D2 Threats, Vulnerabilities, and Attacks (24%)
- [ ] Aktorzy zagrożeń i motywacje
- [ ] Wektory i powierzchnie ataku (użytkownicy, systemy, sieci, chmura, łańcuch dostaw)
- [ ] Wskaźniki złośliwej aktywności
- [ ] Ocena podatności i priorytety mitygacji
- [ ] Ryzyka systemów AI: modele, prompty, prywatność, wyciek danych

### D3 Security Architecture (19%)
- [ ] Chmura, hybryda, on-premises, OT
- [ ] Zasady bezpieczeństwa infrastruktury: kontrola dostępu, segmentacja, łączność
- [ ] Ochrona danych w całym cyklu życia
- [ ] Odporność i odtwarzanie: backupy, redundancja, plany, testy

### D4 Security Operations (27%)
- [ ] Techniki ochrony endpointów, sieci, aplikacji i danych
- [ ] Cykl życia sprzętu, oprogramowania i danych
- [ ] Zarządzanie podatnościami: identyfikacja, priorytety, naprawa, weryfikacja
- [ ] Logi, alerty, dashboardy i narzędzia do wykrywania
- [ ] Uwierzytelnianie, autoryzacja, federacja, dostęp uprzywilejowany
- [ ] Automatyzacja, orkiestracja, praca wspierana AI
- [ ] Reagowanie na incydenty: od przygotowania do lessons learned
- [ ] Analiza dowodów i danych w dochodzeniach

### D5 Security Program Management and Oversight (14%)
- [ ] Polityki, standardy, procedury, wytyczne
- [ ] Ocena, komunikacja i zarządzanie ryzykiem
- [ ] Ryzyko stron trzecich
- [ ] Wymogi prawne, zgodność, prywatność
- [ ] Audyty, przeglądy, testy, oceny
- [ ] Szkolenia i świadomość bezpieczeństwa

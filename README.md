## Zasady repozytorium

1. Notatki własnymi słowami. Nie kopiuję treści płatnych kursów ani pytań z testów próbnych i egzaminu.
2. Zero kodu, nazw i danych z pracy.
3. Zero sekretów (hasła, klucze, tokeny) – także w laby.
4. Projekty do portfolio żyją w osobnych, publicznych repozytoriach; tutaj tylko link.
5. Commit po każdej sesji nauki: `t03: notatki PKI`, `bscp: lab sqli 5`.
